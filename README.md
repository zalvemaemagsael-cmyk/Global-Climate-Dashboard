# Global-Climate-Dashboard

### An interactive data dashboard built with Streamlit and Plotly that visualizes the economic and humanitarian impact of climate events worldwide from 2020 to 2025.

### This dashboard explores 3,000 recorded climate events across 51 countries, covering disasters such as floods, wildfires, droughts, hurricanes, and more. It helps users understand trends in event frequency, economic damage, casualties, international aid, and response effectiveness.
